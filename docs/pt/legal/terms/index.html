8 NR-BOS Licensing

NR-BOS is licensed by single-use redemption code, not by subscription billing inside the product. This section describes exactly how that works, matched to how the licensing system actually behaves:

8.1 Codes Are Single-Use and Non-Transferable

Each license code can be redeemed exactly once. Once redeemed, it is permanently bound to the redeeming company and cannot be reassigned, resold, or transferred to a different company or account.

8.2 Redemption Extends Your Period

Redeeming a code adds its duration to your current license period. If your existing period hasn't expired yet, the new period is added on top of it rather than replacing it; if it has expired, the new period starts from the moment of redemption.

8.3 No Automatic Renewal

A license period ends on its scheduled date. Nothing renews automatically — access is paused until a new code is redeemed. There is no recurring billing associated with NR-BOS licensing.

8.4 No Refunds on a Redeemed Code

Once a code has been redeemed, that redemption is final. We do not offer refunds on a redeemed license code, and redemption does not go through a payment processor capable of a reversal — treat redemption as a deliberate, final action.

8.5 Revocation

We can revoke a license code to prevent it from ever being redeemed — this matters if a code is leaked, issued in error, or no longer should be honoured. Revoking a code that has already been redeemed prevents that specific code from being used again, but does not claw back or suspend the access already granted from that earlier redemption. We are stating this precisely because it's a real limitation, not a stylistic choice: at present, we do not have a separate mechanism to suspend a company's already-granted NR-BOS access. If we need to end an active customer's access for cause, we will contact them directly to arrange it rather than relying on a revocation mechanism that isn't built for that.

8.6 Trial Codes

Certain codes are issued as 3-day trial codes. A company may redeem one trial code, ever — a company that has already redeemed a paid (monthly or annual) code is not eligible for a trial code, and a company that has already used a trial code cannot use a second one.
