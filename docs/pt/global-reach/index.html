Perguntas Frequentes

Perguntas Frequentes

O que conta como uma mensagem?

Cada mensagem de chat que envia numa sala, ou em mensagens 1 para 1, conta para a sua atribuição mensal. Traduzi-la para outros participantes não consome mensagens adicionais.

O que acontece quando as minhas mensagens grátis se esgotam?

As suas salas, quadros brancos e histórico de mensagens permanecem totalmente acessíveis. Enviar mais mensagens de chat traduzidas requer atualizar para um plano pago.

Que idiomas são suportados?

Suporte completo de interface em inglês, sueco, alemão, francês, espanhol, italiano, polaco, neerlandês, português, urdu e árabe, com tradução de chat também disponível para idiomas adicionais.

Os meus dados são privados?

Sim — as mensagens e documentos são tratados de acordo com a nossa Política de Privacidade, conforme o RGPD, que especifica exatamente o que recolhemos e porquê.

Ainda Não Está Pronto?

Receba uma notificação quando novos idiomas forem lançados.
