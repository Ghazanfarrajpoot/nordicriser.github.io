Inside NR-BOS

Nordic Riser Business Operating System — the platform we built to run our own project delivery, and license to other operators. The screenshots below are from a live build, seeded with example project data.

Home › Lavori › NR-BOS
← Back to Work
Overview

A live read on every project

Portfolio-wide KPIs, budget vs. actual spend, and team workload — the first thing anyone opens each morning.

Projects

Every job, tracked to the task

Projects carry their own budget, client, and team. Work inside each one runs on a four-column board — to do, in progress, review, done.

Budget

Spend tracked against budget, by category

Every cost entry — materials, labor, subcontractors, permits — rolls up against the project budget in real time.

Field Work

What happened on site, with proof

Field crews log progress notes and photos straight from the site — including paired before/after shots for work that's easy to describe but hard to picture.

AI Assistant

Risk, cost, and productivity — read by AI

On demand, an AI assistant reads a project's real tasks, costs, and team data and returns a structured risk, cost, or productivity briefing — not generic advice.

Client Reports

A branded PDF, generated in one click

Pull a project's tasks, costs, and recent field photos into a client-ready PDF report — draft first, then mark as sent when it's ready to go out.

Team & Licensing

Role-based access, licensed by code

Admins, project managers, field workers, and clients each see only what's theirs. Access itself runs on redeemable subscription codes, issued in batches — no payment processor required.

Want NR-BOS for your team?

It's licensed by subscription code, not a public sign-up form — tell us about your operation and we'll set you up.
